02 / Transformation

What each path computes

The four breathing paths produce different kinds of information. A normalized waveform is not lung volume; a motion event is not a verified breath.

A / ACC

PCA waveform

Selected H10 axes are smoothed, projected onto a calibrated principal motion axis, then scaled using robust bounds. Its derivative with hysteresis gives phase; like-polarity extrema give cycle rate and dynamics.

breathing_volume · breathing_phase · rate · quality · dynamics

Related chest-ACC PCA research ↗
B / ACC

Phan adaptation

For each H10 axis, compare 0.2 s and 200 s means. Sum the absolute differences, apply an adaptive threshold, and count rising onsets after quiet and refractory gates. Count accepted events over 60 s.

phan_breath_event · phan_breath_rate

Original phone algorithm ↗
C / ACC

Flowborne adaptation

Compare 0.267 s and 2 s means of the signed PCA projection, divided by its calibrated span. Threshold the contrast into inhale (+1), exhale (−1), hold (0), or bad signal (−2).

flowborne_motion_score · flowborne_phase

D / FORCE

Vernier normalization

Forward Go Direct numeric channels unchanged. For the respiration belt's force channel, map each sample into [0, 1] using recent 30 s 5th–95th percentile bounds. Increasing force denotes inhalation.

rawVernier · vernierBreathing

These algorithms are different implementations. The cited papers and source projects explain their origins or related methods; they do not validate Polar Mini's H10 adaptations. 03 / Vernier reference

Respiration Belt variables

These are the four measurement channels verified on a live GDX-RB running firmware 5.3. The belt does not advertise raw X, Y, or Z acceleration channels.

In separate mode, <name>_rawVernier always contains every device measurement plus the diagnostic fields below. <name>_rawForce and <name>_vernierBreathing are also always present. Use the app's Streams checkboxes to add <name>_steps and <name>_stepRate. Single mode uses one sparse <name> outlet with all measurement channels and breathing; the optional checkboxes apply when separate mode is selected.

Raw recording fields

The rawVernier outlet labels the first four channels with device metadata. In single mode those labels have the form sensor_1_Force, sensor_2_Respiration Rate, sensor_4_Steps, and sensor_5_Step Rate. Missing values in a sparse update are NaN, not a repeated prior reading.
